Donor Management System in C++

A console-based Donor Management System developed in C++ to manage donor-related activities, beneficiaries, donations, events, volunteers, resources, and financial records. The project uses file handling to store and retrieve data and provides an interactive menu-driven interface with administrator authentication.

Features
Admin Authentication: Login, change password, add administrators, and remove administrators.
Beneficiary Management: Add, update, delete, search, and view beneficiary records.
Donation Management: Record donations, update and delete donation records, view donations, and generate donation receipts.
Event Management: Create, update, delete, search, and view events, and register participants.
Volunteer Management: Manage volunteer records and assign tasks.
Resource Management: Add, update, delete, search, and view resources, allocate resources, and track remaining quantities.
Financial Management: Record income sources and expenses, generate financial reports, and track budgets.
File Handling: Store records in text files for persistent data management.
Console Interface: Interactive menus with colored text for improved usability.
Technologies Used
C++
Object-Oriented Programming (OOP)
File Handling (ifstream and ofstream)
Standard Template Library (string)
Windows Console API

This project demonstrates the practical application of object-oriented programming, file handling, CRUD operations (Create, Read, Update, Delete), authentication, and menu-driven programming in C++. It is designed as an academic project for learning and practicing software development fundamentals.

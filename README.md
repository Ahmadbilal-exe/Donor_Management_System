Donor Management System in C++


A console-based Donor Management System developed in C++ using Object-Oriented Programming (OOP) and file handling to manage donors, beneficiaries, donations, events, volunteers, resources, and financial records.

Features
🔐 Admin login and password management

👥 Beneficiary management (CRUD)

💰 Donation tracking and receipt generation

📅 Event and participant management

🤝 Volunteer management and task assignment

📦 Resource allocation and tracking

📊 Financial records and reports

💾 File handling for persistent data storage

🎨 Interactive, menu-driven console interface

Technologies Used
C++

Object-Oriented Programming (OOP)

File Handling (ifstream, ofstream)

STL (string)

Windows Console API


Future Improvements
Database integration

Enhanced security

GUI development

Data backup and advanced reporting

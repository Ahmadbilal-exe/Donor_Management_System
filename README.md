Donor Management System in C++

A console-based Donor Management System developed in C++ to manage beneficiaries, donations, events, volunteers, resources, and financial records. It uses file handling for persistent data storage and provides an interactive, menu-driven interface with administrator authentication.


✨ Features

🔐 Admin Authentication: Login, change passwords, and manage administrators.

👥 Beneficiary Management: Add, update, delete, search, and view records.

💰 Donation Management: Record donations, view history, and generate receipts.

📅 Event Management: Create events and manage participant registrations.

🤝 Volunteer Management: Manage volunteer records and assign tasks.

📦 Resource Management: Track, allocate, and manage resources.

📊 Financial Management: Record income and expenses and generate reports.

💾 File Handling: Store and retrieve records using text files.

🎨 Console Interface: Interactive menus with colored text.


🛠️ Technologies Used

Language: C++

Concepts: Object-Oriented Programming (OOP)

File Handling: ifstream and ofstream

STL: string

Interface: Windows Console API

Storage: Text files

🎯 Project Objective

This project demonstrates the practical application of C++ programming, OOP, file handling, authentication, and CRUD operations in a real-world management system. It is suitable for students learning software development fundamentals.
